Button glyphs embedded in the executable (CMakeLists.txt, AC6_FONTS) and used by gpu/texture_mods.cpp as built-in
texture replacements while the settings' Button style is PlayStation. A mod's own file for the same hash wins.

playstation/<hash>.dds: the game's 40x40 face button glyph textures (BC3), by the hash they replace:
  B30926707688AFA7  A  cross
  5815009FFD003F54  B  circle
  567C603ACEC3BEF6  X  square
  62B5B1271CAFB882  Y  triangle

The PlayStation glyphs: made by Ostrich (https://ostrichmods.com/).
